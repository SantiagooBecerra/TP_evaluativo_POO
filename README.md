# TP Evaluativo - Programación Orientada a Objetos
## Abstracción representada: Cajero Automático / Cuenta Bancaria

Este programa simula el funcionamiento básico de un cajero automático.
Permite crear cuentas, depositar, retirar, consultar saldo y ver el historial de movimientos.

### Características
- 2 clases: `CuentaBancaria` y `CajeroAutomatico`.
- Atributos privados (encapsulamiento del saldo).
- Métodos que modifican y consultan el estado del objeto.
- Menú en consola con validaciones de entrada.
- Registro de operaciones realizadas.

### Uso
1. Ejecutar el archivo con `python tp_integrador_poo.py`.
2. Seguir las opciones del menú.
3. Salir con la opción 6.
